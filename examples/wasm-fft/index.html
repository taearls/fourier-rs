fourier-core WASM FFT Roundtrip Demo

This example demonstrates using fourier-core's WASM exports to perform FFT and IFFT in the browser. Build with: 

# Install wasm-pack: https://rustwasm.github.io/wasm-pack/installer/
cd crates/core
wasm-pack build --target web --features wasm

Then serve this directory and import the generated package.

Click "Run FFT Roundtrip" to start...
